
# [コミットメッセージのルール]
# Conventional Commits に従うこと
# 
# # 英語　: https://www.conventionalcommits.org/en/v1.0.0/
# # 日本語: https://www.conventionalcommits.org/ja/v1.0.0/
# 
# [コミットメッセージのプレフィックス]
# コミットメッセージには以下のいずれかのプレフィックスを付けること
# 
# # feat: 新しい機能やファイルを実装したとき
# # --> 例 "feat: 画像をレンダリングする render_image 関数を実装した"
# # --> 例 "feat: cleanup 関数に hoge 変数の free を追加した"
# # 
# # fix: バグや実装ミスを修正したとき
# # --> 例 "fix: window 関数のメモリリークを修正"
# # --> 例 "fix: convert 関数内の暗黙的型変換を修正"
# # 
# # refactor: 入出力や実行結果の差異が実装の変更
# # --> 例 "refactor: parse 関数の行数を削減"
# # --> 例 "refactor: render 関数のアルゴリズムを変更"
# # 
# # style: インデントやコードの見た目だけを変更したとき
# # --> 例 "style: 変数名と関数名を変更"
# # --> 例 "style: 不要なインデントを削除してNorm エラーを修正"
# # 
# # docs: ドキュメントや設定ファイルを変更したとき
# # --> 例 "docs: README.md を作成した"
# # --> 例 "docs: .gitignore に除外する拡張子を追加した"
# # 
# # test: テストの実装や変更をしたとき
# # --> 例 "test: マップファイルのパーステストを実装した"
# # --> 例 "test: レンダリングテストのテストケースを追加した"
#
